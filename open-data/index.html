Open visa requirements dataset

The data is free to use under CC BY-SA 4.0 and refreshed daily.

This is the data behind the travelnow.info map, published as plain files. It holds the visa requirement for every passport and destination pair we track (200 passports, 205 destinations, about 41,000 pairs), the passport ranking, and a log of the policy changes we have detected. You may use it for research, journalism, teaching and your own projects. No sign-up is needed.

Sizes are approximate and grow slightly as the changelog grows. Files are UTF-8; CSV files use a header row and comma separators.

Column dictionary

visa-matrix.csv

  • passport_iso2, passport_name: the passport holder's country, as an ISO 3166-1 alpha-2 code and an English name.
  • destination_iso2, destination_name: the country being entered.
  • status: the entry category, one of the codes below.
  • days: the permitted length of stay in days, when the source gives one. Empty when it does not.

visa-matrix.json holds generated (the data date), source, license, statuses (code to label) and passports. Under passports, each passport code maps to an object of destination codes, and each destination holds [status, days], for example "TR": { "DE": ["vr", null] }.

passport-ranking.csv: rank, passport code and name, no_advance_visa_count (the headline number), easy_access_count (the headline number plus eVisas), then one count per status code. Passports that tie on both numbers share a rank.

changes.csv: date (when we detected the change), passport and destination codes, and the status from and to. A change that affects several passports gets one row per passport.

Embed the checker

Add a visa checker to a blog post or page with one line of HTML. Set to to a destination code (for example jp) and, optionally, from to a passport code. Add lang=tr for Turkish.

<iframe src="https://travelnow.info/embed/?to=jp" width="100%" height="260" style="border:0;max-width:480px" title="Visa checker by travelnow.info" loading="lazy"></iframe>

The visitor picks a passport and sees the entry status and the allowed stay for that destination, read from the same data as this page, with a link to the full rules.

Update schedule

The files are rebuilt every day by the same job that refreshes the site, so they match the map. The generated field in the JSON file gives the date of the underlying data snapshot.

Method and caveats

The base data is read every day from the visa requirement tables that Wikipedia keeps for each nationality. We then apply a hand-curated layer for cases a table cannot express: ID-card travel between neighbouring countries, freedom-of-movement zones, entry bans and territories. Each curated rule is checked against an official source. The files contain the result after that layer, the same status the map shows. How the headline number and the ranking are defined is explained in How to read a passport's visa-free number.

  • Each row describes an ordinary passport with no residence permits. Diplomatic and official passports are not included.
  • Destinations are the territories the map counts. Antarctica and a passport's own country are left out.
  • A visa requirement table can be out of date or wrong. Where we cannot source a fact we leave it out rather than guess, so some cells fall back to the default for that passport.
  • This is not an official source. Confirm any requirement with the destination's embassy or consulate before you travel.

Found a wrong row? Email hello@travelnow.info with the passport, the destination and a source link.
